## 1. 这是什么游戏

KitchenFight 是一款 **2v2 队伍对抗型多人厨房游戏**。两名玩家组成红队，另外两名组成蓝队，各自在对称的厨房中烹饪菜品、完成订单冲分，同时使用"整蛊道具"干扰对手。

一局比赛 **180 秒**（3 分钟），结束时分数最高的队伍获胜。

## 2. 核心玩法

```
烹饪冲分：取食材 → 切菜 → 煎炸 → 组装盘子 → 配送订单 → 得分
整蛊对抗：道具箱/落后补偿获取道具 → 瞄准对手 → 释放效果干扰对方烹饪
```

**三种获取道具的途径**：
1. **地图道具箱** — 厨房中央通道有两个道具箱，交互即可抽取（10 秒冷却）
2. **落后补偿** — 分数落后的队伍定期获得补偿道具，落后越多道具越强
3. **送单奖励**（设计中）— 配送达到里程碑时获得奖励

## 3. 已实现的 4 种整蛊道具

| 道具 | 效果 | 目标 | 直观描述 |
|------|------|------|---------|
| 平底锅敲头 | 眩晕 2 秒 | 对方玩家 | 被敲后原地不能动 |
| 料酒上头 | 方向反转 8 秒 | 对方玩家 | 按上往下走，按左往右走 |
| 保鲜膜封存 | 柜台锁定 15 秒 | 对方柜台 | 选中的柜台不能用了 |
| 清洁湿巾 | 清除自身负面状态 | 自己 | 解除自己身上的所有整蛊 |

## 4. 公平机制

- **镜像配方**：两队同时收到相同的订单，保证公平
- **被整保护**：被整后 10 秒内再次被整，效果减半
- **落后补偿**：分数差距越大，落后方获得的道具越强
- **反制道具**：清洁湿巾可清除自身所有负面状态

## 6. 游戏特色

1. **派对混乱感** — 弱队有翻盘机会，强队优势不稳
2. **厨房主题统一** — 所有道具都是厨房/餐厅真实会发生的事
3. **节奏递进** — 从冷静厨艺博弈逐渐演变成灾难派对
4. **三分钟一局** — 短平快，适合派对/朋友开黑
