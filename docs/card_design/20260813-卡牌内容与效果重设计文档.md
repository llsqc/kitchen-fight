# 20260813-卡牌内容与效果重设计文档

## 一、设计目标

将卡牌分为**单人模式**和**多人模式**两类：

- **单人模式卡牌**：全部为正面增益效果（Buff），作用对象为自己
- **多人模式卡牌**：保留现有的破坏效果（Debuff），作用对象为对手

本文档先设计**单人模式卡牌**，定义每张卡牌的效果、数据配置方式，以及对现有效果系统的改造方案。

卡牌图标暂时使用纯色 Image 占位，不依赖外部 Sprite 资源。

## 二、单人模式卡牌列表

### 2.1 加速跑鞋（MoveSpeedUp）

**效果：** 玩家移动速度提升 50%，持续 10 秒。

**实现原理：**
- `Player.HandleMovement()` 中使用 `moveSpeed` 计算移动距离
- 需要在 `PlayerEffectHost` 中新增 `moveSpeedTimer`（NetworkVariable\<float\>）
- `Player` 读取该计时器，若 > 0 则 `moveSpeed * 1.5f`

**数据配置：**
```
cardName: "加速跑鞋"
effectType: MoveSpeedUp
gameMode: Single
rarity: Common
targetType: Self
duration: 10
magnitude: 1.5
```

### 2.2 灵巧之手（InteractionSpeedUp）

**效果：** 切菜次数减半、煎炸/烧焦速度加倍（更快完成烹饪），持续 15 秒。

**实现原理：**
- `CuttingCounter.CutObjectClientRpc()` 中 `cuttingProgress++`，改为 `cuttingProgress += speedMultiplier`
- `StoveCounter.Update()` 中 `fryingTimer.Value += Time.deltaTime` 改为 `+= Time.deltaTime * speedMultiplier`，`burningTimer` 同理
- 需要在 `PlayerEffectHost` 中新增 `interactionSpeedTimer`
- `CuttingCounter` 和 `StoveCounter` 需要知道操作者的效果状态，通过查询当前交互的 Player 的 `PlayerEffectHost`

**数据配置：**
```
cardName: "灵巧之手"
effectType: InteractionSpeedUp
gameMode: Single
rarity: Rare
targetType: Self
duration: 15
magnitude: 2.0
```

### 2.3 双倍得分（DoubleScore）

**效果：** 成功送餐得分翻倍，持续 20 秒。

**实现原理：**
- `DeliveryManager.DeliverCorrectRecipeServerRpc()` 中 `GetTeamScoreNetworkVariable(teamId).Value++`
- 需要在此处查询玩家是否拥有双倍得分 Buff
- 单人模式下直接对 `team0Score` 加 2 而非 1
- 在 `PlayerEffectHost` 中新增 `doubleScoreTimer`

**数据配置：**
```
cardName: "双倍得分"
effectType: DoubleScore
gameMode: Single
rarity: Epic
targetType: Self
duration: 20
magnitude: 2.0
```

### 2.4 时间延长（ExtraTime）

**效果：** 立即延长游戏时间 15 秒（非持续型，使用即生效）。

**实现原理：**
- `KitchenGameManager` 中 `gamePlayingTimer` 是 `NetworkVariable<float>`，服务端权威
- 卡牌使用时调用 `KitchenGameManager.AddTimeServerRpc(15f)` 新增方法
- 非 Buff 类效果，无 duration，使用后立即生效并销毁卡牌

**数据配置：**
```
cardName: "时间延长"
effectType: ExtraTime
gameMode: Single
rarity: Rare
targetType: Self
duration: 0
magnitude: 15.0
```

### 2.5 完美料理（InstantComplete）

**效果：** 立即将手中正在切的食材完成切菜，或将炉灶上的食材完成煎炸。

**实现原理：**
- 查询玩家当前 `selectedCounter`
- 若是 `CuttingCounter`：直接设置 `cuttingProgress = cuttingProgressMax`，触发完成
- 若是 `StoveCounter`：若处于 Frying 状态直接完成，若处于 Fried 状态直接进入 Burned（跳过）
- 非 Buff 类效果，使用后立即生效并销毁卡牌

**数据配置：**
```
cardName: "完美料理"
effectType: InstantComplete
gameMode: Single
rarity: Epic
targetType: Self
duration: 0
magnitude: 1.0
```

### 2.6 清除疲劳（CleanWipe）

**效果：** 清除自身的所有负面状态（眩晕、反向操作），并恢复少量时间。

## 三、数据结构重设计

### 3.1 现有结构的问题

现有 `SabotageItemSO` 存在以下局限：

1. `EffectType` 枚举只有负面效果（Stun/ReverseControls/LockCounter/CleanWipe）
2. 没有 `gameMode` 字段区分单人/多人
3. 没有 `magnitude` 字段表达效果强度（如 1.5 倍速度、2 倍得分）
4. 命名为 "SabotageItem" 不适合正面效果卡牌

### 3.2 新的 SO 数据结构

创建新的 `CardSO`，替代 `SabotageItemSO`：

```csharp
public enum GameMode {
    Single,       // 单人模式：正面 Buff
    Multiplayer,  // 多人模式：负面 Debuff + 部分正面
}

public enum EffectType {
    // --- 单人模式（正面 Buff） ---
    MoveSpeedUp,          // 加速移动
    InteractionSpeedUp,   // 加速交互
    DoubleScore,          // 双倍得分
    ExtraTime,            // 延长时间
    InstantComplete,      // 瞬间完成
    CleanWipe,            // 清除负面

    // --- 多人模式（负面 Debuff，保留原有） ---
    Stun,                 // 眩晕
    ReverseControls,      // 反向操作
    LockCounter,          // 锁定台面
}

public enum Rarity {
    Common,
    Rare,
    Epic,
}

public enum TargetType {
    Self,     // 对自己使用（单人卡牌 + 多人 CleanWipe）
    Player,   // 对目标玩家使用（多人 Debuff）
    Counter,  // 对目标台面使用（多人 LockCounter）
}

[CreateAssetMenu(fileName = "Card", menuName = "KitchenFight/Card")]
public class CardSO : ScriptableObject {
    public string cardName;
    [TextArea] public string description;
    public GameMode gameMode;
    public EffectType effectType;
    public Rarity rarity;
    public TargetType targetType;
    public float duration;       // 持续时间（秒），0 = 即时效果
    public float magnitude;      // 效果强度（如 1.5 倍速度、2 倍得分、延长 15 秒）
    public Sprite icon;          // 卡牌图标，为 null 时使用纯色占位
    public Color placeholderColor = Color.white;  // 无图标时的占位颜色
}
```

### 3.3 与现有 SabotageItemSO 的关系

| 对比项 | 旧 `SabotageItemSO` | 新 `CardSO` |
|---|---|---|
| 命名 | SabotageItem（破坏道具） | Card（卡牌） |
| 效果类型 | 仅负面（4 种） | 正面 + 负面（9 种） |
| 游戏模式 | 无区分 | Single / Multiplayer |
| 效果强度 | 无 magnitude | 有 magnitude |
| 描述文本 | 无 | 有 description |
| 占位色 | 无 | 有 placeholderColor |

**迁移策略：**
- `CardSO` 是 `SabotageItemSO` 的超集，包含所有原有字段
- 将 `SabotageItemListSO` 改名为 `CardListSO`，持有 `List<CardSO>`
- 原有 `.asset` 文件需手动迁移到 `CardSO`（重新创建并填写字段）
- `KitchenGameMultiplayer` 中的 `sabotageItemListSO` 引用改为 `cardListSO`

### 3.4 CardListSO 结构

```csharp
[CreateAssetMenu(fileName = "CardList", menuName = "KitchenFight/CardList")]
public class CardListSO : ScriptableObject {
    public List<CardSO> cardList;

    public int GetIndex(CardSO card) {
        return cardList.IndexOf(card);
    }

    public CardSO GetFromIndex(int index) {
        if (index < 0 || index >= cardList.Count) return null;
        return cardList[index];
    }

    public List<CardSO> GetCardsByMode(GameMode mode) {
        return cardList.FindAll(c => c.gameMode == mode);
    }
}
```

## 四、效果系统改造

### 4.1 PlayerEffectHost 改造

现有 `PlayerEffectHost` 只管理负面效果（Stun、ReverseControls）。需要新增正面效果的计时器：

```csharp
// 新增 NetworkVariable
private NetworkVariable<float> moveSpeedTimer = new NetworkVariable<float>(0f);
private NetworkVariable<float> interactionSpeedTimer = new NetworkVariable<float>(0f);
private NetworkVariable<float> doubleScoreTimer = new NetworkVariable<float>(0f);
```

**Update() 中计时递减：**
```csharp
if (moveSpeedTimer.Value > 0f) { moveSpeedTimer.Value -= Time.deltaTime; ... }
if (interactionSpeedTimer.Value > 0f) { interactionSpeedTimer.Value -= Time.deltaTime; ... }
if (doubleScoreTimer.Value > 0f) { doubleScoreTimer.Value -= Time.deltaTime; ... }
```

**ApplyEffect 扩展：**
```csharp
public void ApplyEffect(EffectType type, float duration, int sourceTeamId) {
    // ... 原有负面效果逻辑 ...

    // 新增正面效果
    switch (type) {
        case EffectType.MoveSpeedUp:
            if (duration > moveSpeedTimer.Value) moveSpeedTimer.Value = duration;
            break;
        case EffectType.InteractionSpeedUp:
            if (duration > interactionSpeedTimer.Value) interactionSpeedTimer.Value = duration;
            break;
        case EffectType.DoubleScore:
            if (duration > doubleScoreTimer.Value) doubleScoreTimer.Value = duration;
            break;
    }
}
```

**查询方法：**
```csharp
public float GetMoveSpeedMultiplier() {
    return moveSpeedTimer.Value > 0f ? /* magnitude */ : 1f;
}
public float GetInteractionSpeedMultiplier() {
    return interactionSpeedTimer.Value > 0f ? /* magnitude */ : 1f;
}
public bool HasDoubleScore() {
    return doubleScoreTimer.Value > 0f;
}
```

**注意：** magnitude 需要从 SO 传递到 EffectHost。当前 `ApplyEffect` 签名不含 magnitude 参数，需要扩展为：
```csharp
public void ApplyEffect(EffectType type, float duration, float magnitude, int sourceTeamId)
```

### 4.2 Player 改造

**移动速度：**
```csharp
// HandleMovement() 中
float effectiveSpeed = moveSpeed;
if (effectHost != null) {
    effectiveSpeed *= effectHost.GetMoveSpeedMultiplier();
}
float moveDistance = effectiveSpeed * Time.deltaTime;
```

### 4.3 CuttingCounter 改造

**加速切菜：** 切菜进度由 `cuttingProgress++` 改为：
```csharp
float speedMultiplier = 1f;
Player interactingPlayer = /* 获取交互玩家 */;
if (interactingPlayer != null) {
    var host = interactingPlayer.GetComponent<PlayerEffectHost>();
    if (host != null) speedMultiplier = host.GetInteractionSpeedMultiplier();
}
cuttingProgress += Mathf.RoundToInt(speedMultiplier);  // 2x 时一次切两刀
```

**注意：** `CuttingCounter.InteractAlternate(Player player)` 已经接收 Player 参数，可以直接查询。但 `CutObjectClientRpc` 是 ClientRpc，不传 Player。需要修改 RPC 签名传入 Player 的 NetworkObjectReference，或者将速度倍率作为参数传入。

### 4.4 StoveCounter 改造

**加速煎炸/烧焦：** 在 `Update()` 中：
```csharp
case State.Frying:
    float speedMultiplier = GetInteractionSpeedMultiplier();
    fryingTimer.Value += Time.deltaTime * speedMultiplier;
    break;
case State.Fried:
    float speedMultiplier = GetInteractionSpeedMultiplier();
    burningTimer.Value += Time.deltaTime * speedMultiplier;
    break;
```

**注意：** `StoveCounter` 不持有交互者引用。需要在 `Interact(Player player)` 时记录最后操作的玩家，或者查询所有玩家的 EffectHost。推荐方案：在 StoveCounter 中新增 `NetworkVariable<ulong> lastInteractorClientId`，在 Interact 时记录。

### 4.5 DeliveryManager 改造

**双倍得分：** 在 `DeliverCorrectRecipeServerRpc` 中：
```csharp
int scoreToAdd = 1;
// 检查该队伍是否有玩家持有 DoubleScore Buff
// 单人模式：teamId=0，检查 Player.LocalInstance
if (Player.LocalInstance != null) {
    var host = Player.LocalInstance.GetComponent<PlayerEffectHost>();
    if (host != null && host.HasDoubleScore()) {
        scoreToAdd = Mathf.RoundToInt(scoreToAdd * /* magnitude */);
    }
}
GetTeamScoreNetworkVariable(teamId).Value += scoreToAdd;
```

**注意：** 服务器端需要遍历该队伍所有玩家检查 Buff 状态。多人模式下如果多人同队，任一成员有 Buff 即可生效。

### 4.6 KitchenGameManager 改造

**时间延长：** 新增方法：
```csharp
public void AddGameTime(float seconds) {
    if (!IsServer) return;
    gamePlayingTimer.Value += seconds;
}
```

**完美料理（InstantComplete）：** 由 `Player.UseCardServerRpc` 直接处理，根据 `selectedCounter` 类型调用相应逻辑，不需要修改 KitchenGameManager。

public void SetCardData(int id, int itemIndex, CardSO cardSO) {

### 6.2 即时效果卡牌处理

ExtraTime 和 InstantComplete 是即时效果（duration=0），拖拽使用后直接生效，不需要走 EffectHost 计时器。在 `HandleCardDismissed` 中分流：

```csharp
private void HandleCardDismissed(EffectCardUI card) {
    CardSO cardSO = cardListSO.GetFromIndex(card.ItemIndex);
    if (cardSO == null) return;

    if (cardSO.duration <= 0f) {
        // 即时效果：直接在客户端执行或走特殊 RPC
        HandleInstantCard(cardSO);
    } else {
        // 持续效果：走 UseCardServerRpc
        HandleDurationCard(cardSO, card.ItemIndex);
    }
}
```
